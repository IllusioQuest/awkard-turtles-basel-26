\section{Reproducibility}
\label{app:repro}
The case weather and price inputs have \texttt{SOURCE} files in \texttt{data/raw/}.
The reference-house export repeats with identical SHA-256 output hashes
(\texttt{scripts/export\_reference\_house.py}); network experiment rows record their
command lines and fixed seeds. Economic sensitivities reproduce only from the versioned
T-14 snapshot and the arithmetic stated in Section~\ref{sec:economics}; the unmerged
actor-model branch is a release dependency for a self-contained archive.
Network outputs live in \texttt{data/derived/network/experiments/}. The greedy and LP
files are, respectively, \texttt{A\_type1\_share.csv} / \texttt{A\_type1\_share-lp.csv},
\texttt{D\_network\_mix.csv} / \texttt{D\_network\_mix-lp.csv}, and
\texttt{E\_transfer\_delay.csv} / \texttt{E\_transfer\_delay-lp.csv}.
Experiment B uses \texttt{B\_phi.csv}; experiment C uses
\texttt{C\_forecast\_error-lp.csv}. The reservation comparison comes from
\texttt{docs/decisions/0029-type1-heat-budget-reservation.md}.
