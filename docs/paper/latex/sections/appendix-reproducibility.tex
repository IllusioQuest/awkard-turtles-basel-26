\section{Reproducibility}
\label{app:repro}

All inputs are committed with \texttt{SOURCE} files (\texttt{data/raw/}), runs are deterministic
(fixed seeds), and every output row records the command that produced it. The reference-house
export repeats with identical SHA-256 hashes of its outputs
(\texttt{scripts/export\_reference\_house.py}).
